# Changelog

All notable changes to RouteKit Lite are documented here.

## 0.1.2 — 2026-08-19

- Added a versioned save-data schema and automatic post-load migration.
- Added recovery for Pro-shaped, damaged, missing, and out-of-range saved values.
- Added real Ren'Py rollback and save/load round-trip tests.
- Added English and Spanish reliability checklists for manual release testing.
- Confirmed compatibility without defining or replacing the host game's `after_load` label.

## 0.1.1 — 2026-08-10

- Updated the English and Spanish guides now that RouteKit Pro is available.
- Added a direct upgrade path for projects that need multiple characters, custom stats, combined event requirements, and a persistent gallery.
- Added a top-level README to make installation instructions easier to find after extracting the ZIP.

## 0.1.0 — 2026-08-04

- Added configurable affection tracking.
- Added relationship stages and scene-unlock helpers.
- Added responsive relationship hub screen.
- Added an interactive demo with an unlockable memory.
- Added automated core and screen tests.
- Added English and Spanish installation guides.
